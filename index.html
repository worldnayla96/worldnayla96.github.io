Personal Workflow Automation Project

About This Application

BBL-n8n-Automation is a personal-use workflow automation project built with n8n. It helps organize spreadsheet records and associated files.

Google API Integration

The application uses authorized Google Sheets and Google Drive API access to manage spreadsheet data, create files, and organize folders.

Access

This application is intended for private use by authorized account owners. It is not offered as a public service.
