Privacy Policy

BBL-n8n-Automation

Effective Date: November 8, 2026

1. Introduction

BBL-n8n-Automation is a private workflow automation project using self-hosted n8n. It helps the authorized account owner organize transaction records, spreadsheets, and files.

2. Google Data Access

The application requests authorization to access Google Sheets and Google Drive.

Google Sheets access permits reading, creating, editing, and deleting spreadsheets. Google Drive access may permit reading, creating, organizing, editing, and deleting files and folders in the authorized account.

Workflows are intended to operate on spreadsheets, files, and folders configured by the authorized account owner.

3. Purpose of Data Use

Authorized Google data is used to support personal automation tasks, including:

  • Creating daily spreadsheet records.
  • Recording transaction information.
  • Organizing files into dated folders.
  • Updating authorized spreadsheet data.
  • Checking records and preventing duplicates.

Google user data is not used for advertising or unrelated profiling.

4. Data Storage

Spreadsheet and Drive data may remain in the authorized Google account. Workflow configuration, temporary processing data, and execution records may be stored in the self-hosted n8n environment.

The account owner is responsible for controlling access to this environment and its stored information.

5. Data Sharing

Google user data is not sold, provided to advertising partners, or shared with data brokers.

Data is processed through the authorized Google services and the configured private automation environment. Any additional sharing must be necessary for an authorized function or required by applicable law.

6. Data Retention and Deletion

Data is retained as needed for the authorized automation workflows. The account owner may delete stored spreadsheet files and locally retained workflow records.

Google account access can be revoked through Google Account security settings. Revoking access stops future authorized API access but does not automatically delete previously stored records.

7. Google API Limited Use

The application's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

8. Policy Updates

This policy may be updated when the application's functionality or data handling practices change.
